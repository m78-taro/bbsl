bbsl —— 血源诅咒 Windows 版快捷 S/L 工具
=====================================

只支持 Windows 10 / 11，macOS 和 Linux 用不了。
非官方工具，第一次用前建议自己另外备份一份存档。


一、放在哪
----------

把整个 bbsl 文件夹放进游戏目录，也就是 Bloodborne.exe 所在的那个文件夹：

    游戏目录\
        Bloodborne.exe
        user\savedata\        游戏存档，bbsl 会自己找到
        bbsl\
            bbsl.exe          打开这个
            _internal\        bbsl 运行要用的文件，别删别挪
            bbsl_backups\     你的备份都在这里
            bbsl_config.json  你的设置

bbsl.exe 和 _internal 必须在一起，整个 bbsl 文件夹一起拷。


二、怎么用
----------

1. 打开 bbsl.exe，右上角显示"已找到存档"就行
2. 玩的时候让 bbsl 开着（最小化就行），关掉窗口热键就停了

备份：退回标题画面 / 退出游戏  →  按备份
还原：退回标题画面 / 退出游戏  →  按还原  →  继续游戏

例如打 Boss：
    Boss 门口退出游戏 → 按备份 → 进游戏打 → 死了退出游戏 → 按还原 → 再进游戏

默认热键：
              键鼠                  Xbox 手柄
    备份      Shift + 下侧键        LB + Back，按住 0.6 秒
    还原      Shift + 上侧键        RB + Start，按住 0.6 秒

    下侧键 = 鼠标上的"后退"键，上侧键 = "前进"键
    在界面右边点按键框就能改，按 Esc 取消

快照列表：
    - 还原热键还原的是时间最新的那份；想回到更早的，点那一行的"还原"
    - 双击名字可以改名
    - 点锁图标可以锁住，最多锁 5 个，锁住的置顶、不会被自动删
    - 最多留 20 份（锁住的也算），超了从最旧的没锁的开始自动删，上限在右边能调


三、边界情况
------------

在游戏里直接还原没用
    游戏下一次自动存档会把它盖掉。一定要先退回标题画面或者退出游戏。

显示"没找到存档"
    bbsl 文件夹没放进游戏目录。它会从自己的位置往上找 user\savedata，最多找三层。

按热键没反应
    - bbsl 没开着，或者被关掉了
    - 右边选的不是你正在用的那套（键鼠 / 手柄只能二选一）
    - 游戏以管理员身份运行，bbsl 也得以管理员身份运行，反过来也一样

还原提示"存档文件被占用"
    游戏正在用存档。退回标题画面或者退出游戏再按。这种情况下 bbsl 什么都不会改。

存档没变的时候按备份
    不会多出一份一样的，只会把上一份的时间刷新一下（改过名的、锁住的除外）。

看不到屏幕上方的弹窗
    游戏要开"无边框窗口"模式，独占全屏会把弹窗盖住。提示音不受影响。

手柄
    - 只支持 Xbox 手柄（XInput）。PS 手柄用 Steam 输入或 DS4Windows 转成 Xbox 手柄可能能用，没测过
    - 没插手柄只能用键鼠；插上会自动切到手柄
    - 插着手柄也想用键鼠：右边点一下"键鼠"，之后就不会再自动切过去
    - 手柄组合至少两个键，必须按住 0.6 秒，多按了别的键不算

锁满了
    最多锁 5 个，想锁新的得先解锁一个。

开了两个
    只能开一个，再打开一次只会把已经开着的那个叫到前面来。

杀毒软件报毒
    全局热键要在后台监听键鼠，又是打包出来的程序，容易被误报。

每份备份大约 14 MB
    存档里 10 个角色槽位不管用没用都会原样复制。

升级到新版本
    把旧 bbsl 文件夹里的 bbsl_backups 和 bbsl_config.json 复制到新版本的 bbsl 文件夹里。

删掉 bbsl
    直接删 bbsl 文件夹。备份也在里面，想留的先拷出来。


非官方工具，和 FromSoftware、索尼，以及 bbport、bbhost 等 PC 移植和启动器项目都没有关系。
第一次用之前，建议自己另外备份一份存档。
